# Platform modules

Loader-spezifische Implementierungen werden hier getrennt gehalten.

- `fabric/common`: Fabric-Code, der über mehrere Minecraft-Familien stabil ist.
- `neoforge/common`: NeoForge-Code, der über mehrere Minecraft-Familien stabil ist.

Family-spezifische Loader-Anpassungen gehören nicht hierher, sondern nach
`families/<family>/<loader>`.
