# Minecraft 1.20.1 Functional Test Matrix


> **Runtime dependency (Fabric):** Install Fabric API `0.92.2+1.20.1` (or a compatible newer 1.20.1 release). Its `fabric-resource-loader-v0` module is required for FlTerraForged's bundled world-preset data pack to participate in the 1.20.1 worldgen registry reload.


This matrix validates the first functional FlTerraForged Minecraft binding:
Minecraft **1.20.1 + Fabric**, external `FlTerraForged-Engine`, native biome routing,
vanilla NoiseRouter/aquifers/surface rules/carvers/features/structures, and Engine-controlled
surface terrain.

The matrix is deliberately split into gates. Do not continue to a later gate if a mandatory
case in an earlier gate fails.

## 1. Test environment

Use a clean test installation and do not reuse chunks generated by an older FlTerraForged build.

Recommended baseline:

| Item | Value |
| --- | --- |
| Minecraft | 1.20.1 |
| Loader | Fabric |
| Java used to run Minecraft/server | 17 |
| FlTerraForged | current test artifact |
| External Engine | matching published `0.1.0-SNAPSHOT` |
| Gamemode | Creative for manual validation |
| Cheats / operator | enabled |
| Render distance | >= 16 chunks for visual seam checks |
| Simulation distance | >= 10 chunks |

For a dedicated server, use:

```properties
level-type=flterraforged:flterraforged
level-seed=8675309
```

Delete or rename the previous world directory before changing the seed or FlTerraForged build.

### Required test seeds

Use at least these seeds:

| Seed | Purpose |
| --- | --- |
| `8675309` | primary regression seed |
| `0` | zero-seed edge case |
| `-1` | signed-seed edge case |
| `1234567890123456789` | large positive long seed |

The primary matrix may be executed on `8675309`; the other seeds are required for the shortened
seed regression gate.

## 2. Result notation

Use one of:

- `PASS` — requirement met.
- `FAIL` — requirement not met; record coordinates, log excerpt and screenshot.
- `BLOCKED` — test could not be executed because an earlier requirement failed.
- `N/A` — only when the test is explicitly optional.

For every `FAIL`, capture at least:

1. FlTerraForged artifact/revision and Engine artifact/revision.
2. Minecraft seed.
3. Dimension.
4. Exact block coordinates.
5. Relevant `latest.log` excerpt.
6. Screenshot; use F3 and, for border tests, F3+G.
7. Whether the defect survives a server/client restart.

# 3. Release gate for the 1.20.1 reference adapter

The Minecraft 1.20.1 Fabric reference adapter is considered **functionally validated** when:

- Every `P0` case is `PASS`.
- No unresolved terrain corruption, chunk-border seam or determinism issue exists.
- At least one `P1` test has been executed for every functional area.
- The primary seed has been explored to at least 10 km from spawn.
- Seeds `0`, `-1` and `1234567890123456789` pass startup + basic terrain + determinism smoke tests.
- Caves, ores/features and at least village/mineshaft/stronghold have been observed; full aquifer-fluid restoration is a post-r19 adapter gate.
- A two-player concurrent-generation test has completed without deadlock or corruption.

Only after this gate should the 1.20.1 binding be used as the reference implementation for the
next Minecraft API family.

## 5. Recommended execution order

For a normal candidate build:

```text
A  Startup / preset
↓
B  Terrain
↓
C  Biomes / climate
↓
D  Rivers / coasts
↓
E  Caves / aquifers
↓
F  Surface rules
↓
G  Features / ores
↓
H  Structures
↓
I  Chunk borders
↓
J  Determinism
↓
K  Stability / performance
↓
L  Multiplayer / lifecycle
```

For a small code-only fix that cannot affect worldgen semantics, rerun at minimum A, I, J01/J02
and the functional area touched by the change. Any change to Engine sampling, seed handling,
DensityBridge, BiomeSource, SurfaceGuard or chunk generation requires the complete P0 matrix.
