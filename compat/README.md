# Optional compatibility

Kompatibilitätsmodule dürfen keine Kernabhängigkeiten erzeugen.

Geplant:

- `terrablender`: optionale Biome-Integration;
- `conquest`: optionale Conquest-Reforged-Material-/Surface-Integration;
- `layers`: generische fractional layer / surface pipeline nach Auswertung der AronaLayers-Ansätze.
